Getting started with Lunta

Lunta: reader and reference manager · for Mac, iPhone, iPad, Android, Windows and Linux

Contents: 1. Choose your setup · 2. Install · 3. Bring your library · 4. First steps · Help

1. Choose your setup

Your library (papers, PDFs, reading views, highlights and notes) is kept in your own cloud storage, not on a Lunta server. Which storage depends on your devices:

Your devicesWhere the library livesWhat to do
Mac, iPhone, iPad onlyiCloud DriveNothing: be signed in to iCloud and the library syncs by itself.
A Mac (and iPhone/iPad) plus Android, Windows or LinuxiCloud Drive, with a copy in Google DriveOn the Mac, choose Lunta › Google Drive for Android… and connect your Google account. Sign in with the same account on Android, Windows or Linux. The Mac passes changes between the two while Lunta is open on it, every few minutes.
Android, Windows or Linux onlyGoogle DriveSign in with your Google account in the app. Lunta keeps its library in a Lunta folder in your Drive.

2. Install

  • Mac, Windows, Linux, Android: download from the latest release (the page says which file you need). The Mac app is signed and notarized by Apple.
  • iPhone and iPad: through TestFlight for now (ask for the invite link), and the App Store soon.
  • Chrome extension (Mac, Windows, Linux): saves the paper you're looking at, with its PDF, using the access your browser already has, and turns a journal's article page into the reading view (Use this page's full text). Download Lunta-…-Chrome-Extension.zip from the latest release and unzip it somewhere permanent; open chrome://extensions, turn on Developer mode, click Load unpacked and choose the folder. Lunta must be open on the same computer. On Android, use a paper's Journal page in Lunta instead.
  • Word and Google Docs (Mac): cite from your library. In Lunta, choose Lunta › Citations in Word & Google Docs… and follow the steps there; see Lunta Citations.

3. Bring your library from Zotero, Mendeley, ReadCube, EndNote…

Lunta imports BibTeX (.bib) and RIS (.ris) exports from any reference manager. Titles, authors, DOIs, tags and notes come along, PDFs too where the export points to them, and duplicates are merged.

On iPhone and iPad: put the export's folder in iCloud Drive (or zip it and AirDrop the ZIP), tap + › Import Library and choose the folder, the ZIP or the .bib / .ris file. Lunta finds the export in the folder and the PDFs with it, and asks whether to put the papers in a folder.

On the Mac: File › Import from Zotero, Mendeley, ReadCube, EndNote… (⇧⌘I). The import asks for

  1. the export file,
  2. optionally, a folder of PDFs, which Lunta matches to the papers by DOI or title, and
  3. whether to put the papers in a folder. Exports don't include your folders, so to keep a collection, export it on its own and import it into a folder of the same name (Lunta suggests the file's name: Thesis.bib goes into Thesis). Repeat for each collection you want to keep; papers in several collections end up in several folders, not duplicated.

Zotero

File › Export Library… (or right-click a collection › Export Collection…), format BibTeX, tick Export Files. Choose the .bib file in Lunta; the PDFs in the export's files folder come along.

Mendeley

Mendeley Reference Manager: select the papers (a collection, or ⌘A for all), then File › Export… as BibTeX. The export doesn't include PDFs: after importing, use File › Find Missing PDFs for open-access papers, and File › Import Folder of PDFs… for PDFs you have in a folder. Mendeley Desktop (the older app): File › Export… as BibTeX; choose Mendeley's PDF folder (Tools › Options › File Organizer) when Lunta asks for a folder of PDFs.

ReadCube Papers

Select the papers, Export › BibTeX, and also Export PDFs to a folder; choose both in Lunta.

EndNote

File › Export… with the output style RefMan (RIS) Export. When Lunta asks for PDFs, choose the library's .Data/PDF folder (next to the .enl file).

Paperpile, JabRef, BibDesk

Paperpile: Settings › Export as BibTeX; its PDFs are in the Paperpile folder in your Google Drive. JabRef and BibDesk: choose the .bib file directly; linked PDFs are copied in.

4. First steps

  • Add a paper: the + button (⇧⌘N on the Mac) with a DOI, PubMed ID or arXiv link; drop PDFs on the list; or share a page from Safari or Chrome.
  • Read: open a paper for its reading view: text that fits the screen, tappable figures and citations, themes, scroll or turn pages. The PDF is one tap away.
  • Highlight: select text and pick a colour, or turn on highlight mode (the highlighter button) to highlight every selection at once. On iPad, draw with Apple Pencil.
  • Organize: folders, tags, stars, Smart Folders and the Must Read list.
  • New for You: describe your research once, and every morning Lunta picks new papers for you.
  • Listen and ask: have a paper read aloud, or ask questions about it; both run on your device.
