iPhone and iPad

Lunta for iPhone and iPad is on the App Store, free. The Safari extension comes with it. It needs iOS 18 or iPadOS 18 or newer.

Download on the App Store

Mac, Windows, Linux and Android

Lunta for computers and Android is published on GitHub. Open the latest release and download the file for your device; its name carries the version number, for example Lunta-1.1.0-Mac-AppleSilicon.zip.

On the Mac before macOS 26 and on iPhone and iPad before iOS 26, Lunta works the same except for the assistant (Ask), the Summary card, the summaries in New for You and suggested topics: they need Apple Intelligence (macOS 26 or iOS 26) or the open model (macOS 27 or iOS 27).

The Source code files on the release page are the project's code at that version; you don't need them to use Lunta.

Browser extension

The extension saves the paper you're looking at to Lunta, with its PDF, using the access your browser already has (your institution's subscription, for example). On a journal's article page, Use this page's full text turns the page into the paper's reading view; on PubMed, Find PDF gets a free, legal copy. With Lunta for Mac, Windows or Linux it also adds a Lunta button to Google Docs for citing. Lunta must be open on the same computer: the extension talks only to the app, never to a server.

Chrome, Edge, Brave and other Chromium browsers

The extension is in review for the Chrome Web Store. Until it is there, install it from the release:

  1. Download Lunta-…-Chrome-Extension.zip from the latest release and unzip it. Keep the folder somewhere permanent (the browser loads the extension from it).
  2. Open chrome://extensions (Edge: edge://extensions) and turn on Developer mode (top right).
  3. Click Load unpacked and choose the unzipped folder.
  4. Pin it: click the puzzle piece in the toolbar, then the pin next to Lunta.

To update, unzip the new version over the old folder and click ↻ on the extension in chrome://extensions.

Firefox

Install it from Firefox Add-ons: Lunta for Firefox › Add to Firefox. Updates come by themselves.

Safari on Mac, iPhone and iPad

The extension comes with the Lunta app, so there's nothing to download.

  • Mac: open Lunta once, then in Safari choose Safari › Settings › Extensions, tick Lunta and allow it on all websites.
  • iPhone and iPad: in the Settings app, Apps › Safari › Extensions › Lunta: turn it on and allow it on all websites. On an article page, open Safari's extensions menu (the puzzle piece, or aA) and choose Lunta.

Android

Chrome for Android has no extensions. Instead, open a paper's Journal page in Lunta, sign in there if needed, and tap Use this page's full text.

Updates

Lunta updates itself on Mac, Windows, Linux (AppImage) and Android: once a day it asks GitHub whether there is a newer version and offers to install it. Check for Updates is in the Lunta menu on the Mac, and under Settings elsewhere, where the daily check can be turned off. The Linux .deb is updated by downloading the new one; Lunta says when there is one. Lunta 1.0.5 and earlier don't update themselves: download the newest version once more by hand. The iPhone and iPad app is updated by the App Store.

One library on all your devices

On a Mac, iPhone or iPad, Lunta asks the first time where the library should live: iCloud Drive, or a Lunta folder in Google Drive (which Android, Windows and Linux use too). To keep iCloud and still use Android, Windows or Linux, on the Mac choose Lunta › Also Sync with Google Drive…, and the Mac keeps the two in sync. More in Getting started.
